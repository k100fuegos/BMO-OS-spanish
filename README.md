Una pequeña recreacion de la pantalla de BMO de Hora de Aventura echo en la web
Contiene efectos de sonido, reacciones y 3 pequeños juegos, 
Fue echo con IA y bastante imaginacion y correciones, 
Creado por diversion

Tambien admite entrada de un mando de xbox, se recomienda utilizar el emulador de DS4
